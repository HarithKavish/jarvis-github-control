# jarvis-github-control

A small static page (`index.html`, `style.css`, `script.js`) used as a control
surface for the Jarvis GitHub automation.

## Local preview

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Files

| File | Purpose |
|---|---|
| `index.html` | Page markup |
| `style.css` | Styling |
| `script.js` | Page behaviour |
